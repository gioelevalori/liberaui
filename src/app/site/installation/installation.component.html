Setting up library in an Angular CLI project.

Angular compatibility

LiberaUI 0.5.1 declares support for Angular 17, 18, 19, 20 and 21.

Library and site builds are verified with Angular 19. A standalone Angular 21.2.25 consumer compiles with strict templates, forms and CSS animation components. Angular 17, 18 and 20 have not been independently tested.

Keep all Angular packages in your application on the same version. Animations use CSS and need no Angular animation providers.

Install libera-ui@^0.5.2 from npm for the latest release.

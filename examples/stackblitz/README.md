# LiberaUI starter

A small zoneless Angular 21 application that uses the published `libera-ui` package: forms, a sortable data table, a dialog, a tooltip and toasts.

[Open in StackBlitz](https://stackblitz.com/github/gioelevalori/liberaui/tree/master/examples/stackblitz)

Run it locally with `npm install` and `npm start`. Documentation: [liberaui.js.org](https://liberaui.js.org).
